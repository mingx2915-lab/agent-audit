## Parking Lot

以下内容未经重新评估不得进入当前里程碑：

- 完整 IAM 或 SSO 集成；
- 通用 OWASP Agentic Top 10 扫描；
- 任意外部 Endpoint 扫描；
- 多租户、计费、组织管理；
- 微服务拆分与分布式任务系统；
- 大规模攻击 Prompt 库；
- 自研模型或模型训练。
- PPT、视频、申报排版和宣传材料（用户明确恢复材料阶段前）；
- 未注明来源、被误写成团队亲访的公开访谈结论。
